Upload the monthly IPPT/NS FIT monitoring reports. A snapshot is the full set of six reports for one report date — the upload is atomic per date (all six land, or none do). Re-uploading a report date replaces its previous ingest. The reports are exported from the OneNS app in either of two forms: the single All Tabs workbook (All_Tabs_Export_YYYYMMDD.xlsx, one tab per report) or the six separate files with canonical names {REPORT}_{STATE}_{YYYYMMDD}.csv (e.g. IPPT_COMPLETED_20260911.csv); each file may be either CSV or Excel (.xlsx) and the set may mix the two formats. The All Tabs CSV export is not accepted — it flattens the tabs, losing which report each row came from.

Upload the reports

Either the single All Tabs workbook All_Tabs_Export_YYYYMMDD.xlsx (tabs are checked as soon as you select it), or all six files — IPPT_COMPLETED_*, IPPT_FAILED_*, IPPT_NOT_ATTEMPTED_*, NSFIT_COMPLETED_*, NSFIT_IN_PROGRESS_*, NSFIT_NOT_STARTED_* — all with the same YYYYMMDD date. Columns are matched by header name; rows that fail validation are quarantined, not dropped.

Upload the defaulter report

The quarterly defaulter release — a .csv, or an .xlsx whose first tab carries the data. The quarter is not in the file: pick which workyear quarter the release represents. The workyear runs 1 Apr – 31 Mar, so Q1 = Apr–Jun, Q2 = Jul–Sep, Q3 = Oct–Dec, Q4 = Jan–Mar of the following year — the Year field is the workyear's starting year (a Jan–Mar release belongs to the previous year's workyear). Sections are matched by header name; rows that fail validation are quarantined, not dropped. Re-uploading the current quarter replaces it (reason/remarks annotations are dropped with its rows); uploading any other quarter archives the previously current one; an archived quarter cannot be re-uploaded. If the direct XLSX export opens encrypted in Excel (“IRM-protected”), re-save it unencrypted first or use the CSV.
